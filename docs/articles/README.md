# 連載記事

**10日で作る Django CMS ― 基礎からワンタイムコード・パスキー認証まで**

各記事は次の13項目で統一しています。

1. 今日の結論
2. 今日の完成画面
3. 今日変更するファイル
4. 完成コード
5. コードの意味
6. 内部で起きていること
7. コマンドの説明
8. よくあるエラー
9. 動作確認
10. セキュリティ上の注意
11. 今日の復習問題
12. Git の差分
13. 次回予告

「8. よくあるエラー」は想像で書いていません。
[`docs/errors/`](../errors/) に記録した、**実際に手が止まったもの**だけを載せています。

「2. 今日の完成画面」の画像は、このリポジトリには入れていません。
代わりに次のマーカーを置き、ブログへ投稿するときだけ実際の画像へ差し替えます。

```text
<!-- screenshot: day-08-login.png | ログイン画面 -->
```

HTML コメントなので GitHub 上では表示されません。
どの画面のことかは、マーカーの直前の文が説明しています。
画像が必要になったら `python tools/capture_screenshots.py` で撮り直せます。

## 読み方

記事を読むだけでも進められますが、手元で動かすと理解が早いです。

```bash
git clone https://github.com/kurumonn/DjangoCMS.git
```

その日の状態へ移動します。

```bash
git checkout day-03
```

前日から何が変わったかを見ます。

```bash
git diff day-02 day-03
```
