# 開発中に実際に起きたエラーの記録

このフォルダには、KururuCMS を作る過程で **実際に発生した** エラーだけを記録しています。
「起きそうなエラー」の想像ではなく、手が止まった事実の記録です。

各記事の「よくあるエラー」節は、ここからそのまま引用します。

## 書式

エラー1件につき、次の5点を書きます。

| 項目 | 意味 |
| --- | --- |
| 症状 | 画面やターミナルに実際に出た文言 |
| 再現条件 | どの操作でそうなるか |
| 原因 | なぜそうなるか（仕組みの説明） |
| 直し方 | 実際に適用した修正 |
| 判断方法 | 直ったことをどう確かめるか |

「原因」を必ず書くのは、同じ症状でも原因が違えば直し方が変わるためです。
エラーメッセージと修正コードだけを並べた記事は、少し状況がずれると役に立ちません。

## テストが全通過していたのに見つかったバグ

このシリーズで特に強調したい2件です。どちらも **実際に画面を出して目で見た** ことが
発見のきっかけでした。

| 日 | 内容 | 見つけ方 |
| --- | --- | --- |
| 6日目 | サイトマップと canonical URL が別ドメインを指していた | ブラウザーで robots.txt と sitemap.xml を開いた |
| 9日目 | 編集者が他人の記事を編集できず 403 になっていた | 記事用のスクリーンショットを撮ろうとした |

テストは「壊れたことに気づく」ためのものであって、
「正しいことを保証する」ものではありません。
